# Daily English Telegram Bot

매일 아침 6:30(KST)에 [@shahn01bot](https://t.me/shahn01bot) 텔레그램 봇으로
일상 영어 문장 10개를 자동 발송하는 기능입니다.

발송은 코드가 아니라 Claude Code **Routine**(예약 실행)이 담당합니다. Routine이
매일 새 세션을 띄워 아래 포맷대로 콘텐츠를 새로 생성한 뒤, Telegram Bot API로
직접 전송합니다. 이 문서는 그 포맷 스펙과 예시입니다.

## 콘텐츠 포맷 — "영어 먼저, 한글은 나중에"

영어를 먼저 전부 읽고 스스로 발음/해석을 시도해본 뒤, 정답(한글)을 확인하는
구조입니다. 그래서 하나의 메시지에 영어+한글을 섞지 않고, **두 개의 메시지**로
분리해서 보냅니다.

### 메시지 1 — 영어만 (한글 번역 없음)

- 상단에 오늘 날짜(KST)와 요일별 오늘의 주제
- 문장 10개, 각 문장마다:
  1. **영어 문장** (굵게)
  2. 🔤 **발음기호 (IPA)** (코드체)
  3. 🗣️ **연음/생략 등 실제 원어민 발음 설명** — 한글로 (예: "What are you doing?" → "Whadaya doin'?" 같은 축약/연음을 어떤 소리가 합쳐지고 빠지는지 설명)

### 메시지 2 — 한글 해석 + 단어 분석 (정답 확인용)

- 🇰🇷 한글 해석: 메시지 1의 번호와 매칭되는 10개 문장의 번역만 (영어/IPA 반복 없음)
- 📚 주요 단어 분석: 10문장에서 뽑은 핵심 단어/표현 8~12개, 품사·의미·사용 노트

Telegram `parse_mode=HTML`로 `<b>`(굵게)·`<code>`(IPA용 코드체)만 사용해
가독성 있게 정리합니다 (MarkdownV2는 이스케이프 오류 위험이 커서 사용하지 않음).

주제는 요일별로 로테이션하여 반복을 줄입니다
(월-회사/업무, 화-쇼핑/일상, 수-음식점/카페, 목-여행/교통, 금-소셜/약속, 토-취미/여가, 일-집/가족).

## 예시 (샘플 1일치 — 일상 대화 표현)

**메시지 1**

🗓️ 2026-07-13 (월) · **오늘의 주제: 일상 대화**

**🇺🇸 오늘의 영어 문장**

1. **I'm running a little late.**
   🔤 `/aɪm ˈrʌnɪŋ ə ˈlɪtl leɪt/`
   🗣️ "running a"는 이어져서 "runnin-a"처럼, "little"의 t는 flap 되어 "li-dl"에 가깝게 들림. 전체적으로 "I'm runnin' a li'l late"처럼 빠르게 발음.

2. **Can you pass me the salt?**
   🔤 `/kən jə pæs mi ðə sɔːlt/`
   🗣️ "Can you" → "Can-ya" /kənjə/로 축약, "the"는 약화되어 짧게 /ðə/.

3. **What are you up to this weekend?**
   🔤 `/wʌt ər jə ʌp tə ðɪs ˈwiːkˌɛnd/`
   🗣️ "What are you" → "Whadaya" /wʌdəjə/ (t가 d로 flap, are·you가 하나로 이어짐), "up to" → "up-tə".

... *(4~10번 생략, 실제 발송본에는 10개 모두 포함)*

**메시지 2**

**🇰🇷 한글 해석**

1. 저 조금 늦어요.
2. 소금 좀 건네줄래?
3. 이번 주말에 뭐 할 거야?

... *(4~10번 생략)*

**📚 주요 단어 분석**

- **run late** (구동사): 늦다
- **pass** (동사): 건네주다
- **up to** (전치사구): ~하는 중인, 계획 중인

## Obsidian 노트 저장

iCloud에는 클라우드 세션에서 직접 쓸 수 있는 공개 API가 없어서(애플이 제공하지
않음), 완전 자동으로 iCloud 폴더에 파일을 넣는 것은 불가능합니다. 대신:

- 매일 텍스트 메시지 2통에 더해, 영어+IPA+연음 설명+한글 번역을 한 파일에 합친
  **Obsidian용 마크다운(.md) 노트**를 만들어 Telegram **문서(파일)**로 함께 전송합니다.
  받는 사람은 텔레그램에서 "파일에 저장"으로 iCloud Obsidian 볼트에 바로 저장할 수 있습니다.
- 동시에 이 저장소의 `daily-english/notes/<날짜>-<주제>.md`에도 백업 커밋을 시도합니다
  (best-effort — 실패해도 텔레그램 발송에는 영향 없음).

## 발송 방식

- Claude Code **Routine**을 매일 06:30 KST(=21:30 UTC 전날)에 실행되도록 예약. (매번 새 세션을 띄우는 `create_new_session_on_fire` 방식)
- Routine 프롬프트가 위 포맷에 따라 새로운 10문장을 생성하고, 요일별 주제로 로테이션.
- 생성된 텍스트를 Telegram Bot API(`sendMessage`, `parse_mode=HTML`)로 `https://t.me/shahn01bot` 채팅으로 전송.
- 영어 블록(메시지 1)과 한글+단어 분석 블록(메시지 2)을 항상 분리 전송.
- 이어서 통합 Obsidian 노트를 `sendDocument`로 파일 첨부 전송하고, 저장소에도 백업 커밋 시도.
